note=The collector RCA loop ticks every 500 ms (tokio interval in crates/mesh/src/main.rs run_collector), so one diagnostic tick is the natural time unit. One sim step maps to one real diagnostic tick (E3 calibration). Measured edge median 481 ms is within +/-20% of one tick, and the P95 (867 ms) is within +/-20% of the simulation's own P95 (2 ticks). The per-device cut is a Kubernetes NetworkPolicy, which blocks only NEW connections, so each edge service recycles its cloud socket (gen-k8s sets --conn-recycle-ms 1200) and the harness injects the fault 1500 ms after it applies the cut: every pre-cut stream (age up to 1200 ms, plus one 200 ms report interval) is re-blocked by about 1400 ms, before the fault is visible at 1500 ms, so no post-fault sample rides an old stream to the cloud and the cloud is blind on every event. The recycle stays loose enough that the reconnect rate is close to a single persistent connection, so it does not inflate the edge diagnosis time.
